# 940-control

مستودع **عام** مخصص للتحكم بإصدارات تطبيقات 940 (Android وWindows). **بيانات تحكم فقط** — لا كود تنفيذي ولا بيانات مستخدمين.

> لا تحتوي نسخة 1.13.2 على بوابة تحكم. أول نسخة مُدارة هي **1.13.3**.

## الفصل الصارم بين ثلاث طبقات
| الطبقة | أين | من يكتب |
|---|---|---|
| **المنشور (عام)** | فرع `gh-pages`: ملف `manifest.json` الموقَّع فقط (+ `.nojekyll`) | الـWorkflow فقط (`publish.yml`) |
| **المصدر / الإعداد** | فرع `main`: `control.json` + `schema/` + `scripts/` + `keys/public/` + workflows | المالك فقط |
| **المفاتيح الخاصة** | **ليست هنا إطلاقًا** | k1: GitHub Secret في بيئة `publish`. k2: عند المالك خارج GitHub |

## كيف يعمل
1. تعدّل `control.json` (من الجوال أو الحاسوب) وتحفظه على `main`.
2. `publish.yml` يتحقق (schema وقواعد الأمان) ويفحص الأسرار ويطلب موافقتك (بيئة `publish`).
3. يوقّع بـk1 ويتحقق من التوقيع بالمفتاح العام، ثم ينشر `manifest.json` إلى `gh-pages`.
4. التطبيقات (بدءًا من 1.13.3) تقرأ الرابط بصلاحية قراءة فقط وتتحقق من التوقيع بمفتاح عام مضمّن فيها.

الرابط (بعد تفعيل Pages): `https://alaimer.github.io/940-control/manifest.json`

## الصيغة المنشورة (envelope)
```json
{ "v": 1, "kid": "k1", "payload": "<base64url لبايتات JSON>", "sig": "<base64url ECDSA P-256 / SHA-256 / IEEE-P1363>" }
```
التوقيع على بايتات الـpayload المفكوكة نفسها (بلا توحيد نصّي). لا يُحلَّل JSON إلا بعد نجاح التحقق. **التطبيق لا يعتمد أي رابط تنزيل قادم من الـmanifest إلا إذا طابق القائمة البيضاء** (انظر `scripts/lib.js`).

## الحالات والأولوية (ينفذها التطبيق في المرحلة التالية)
`maintenance` ← `blocked` ← `force_update` (صريح أو أقل من `minimum`) ← `update_available` (صريح أو أقل من `latest`) ← `active`.
- `maintenance.until` يُنهي الحجب تلقائيًا بعد انقضائه؛ `blocked` و`force_update` لا ينتهيان تلقائيًا (يلزم manifest موقَّع أحدث).
- `offlineGraceDays`: الافتراضي 3 (72 ساعة)، بين 1 و7 (الحد الأقصى ثابت داخل التطبيق أيضًا).
- `sequence` يزيد تلقائيًا في كل نشر ويمنع الرجوع إلى manifest أقدم.

## قواعد أمان تفرضها `validate`
منع إيقاف/إجبار أحدث إصدار، `minimum <= latest`، رسالة مطلوبة للإيقاف والصيانة، حد لـ`until`، رسائل بلا محارف تحكم/اتجاه مخفية، حقول غير معروفة مرفوضة، وروابط التنزيل: HTTPS فقط ومن `github.com/alaimer/940-control/releases/download/` أو `ars.gov.sa` ونطاقاتها الفرعية، بلا منفذ ولا بيانات اعتماد ولا query، بامتداد `.apk`/`.exe`.

## الاختبار
`npm test` (Node ≥ 20، بلا اعتماديات). المفاتيح في الاختبارات تُولَّد في الذاكرة فقط ولا تُكتب على القرص.

## إعداد لمرة واحدة (إجراءات المالك)
انظر `keys/README.md` و`SECURITY.md`.

## التطوير المستقبلي
هذا المستودع مصدر مؤقت لـVersion Control. عند وجود Backend/API مركزي (مستخدمون وأدوار وصلاحيات ونطاق بيانات) تُنقل الخدمة إليه مع بقاء **صيغة المغلّف الموقَّع نفسها**، فلا يتغير كود التحقق في التطبيقات. صلاحيات الوصول للبيانات تُفرض في الخادم، ولا تُوضع في هذا الـmanifest إطلاقًا.
